# سجل القرارات والافتراضات

> أي قرار جديد يتعارض مع قرار هنا يجب توضيحه ومراجعة تأثيره مع مالك المنتج قبل التنفيذ.

## أ) قرارات المنتج

| # | القرار |
|---|---|
| D-01 | المنتج قالب يُباع لأكثر من منشأة، **نسخة مستقلة لكل منشأة** (كود واحد + قاعدة بيانات منفصلة). |
| D-02 | المنشأة الواحدة تحتوي عدد غير محدود من الأماكن، وكل مكان يُحجز مستقلًا وتعمل الأماكن بالتوازي. |
| D-03 | الـ MVP نظام داخلي فقط، بلا صفحة عامة للعميل. |
| D-04 | السوق مصر، عربي فقط (RTL)، جنيه مصري، توقيت القاهرة؛ الكود مُجهّز للترجمة. |
| D-05 | لكل مكان فترتان افتراضيتان (نهاري ومسائي) بمواعيد تحددها القاعة، واليوم الكامل = بداية النهاري حتى نهاية المسائي. |
| D-06 | كل حجز مرتبط بفترة (نهاري/مسائي/يوم كامل) وسعره منها. يمكن تعديل ساعة البداية والنهاية تعديلًا بسيطًا بشرط عدم التعارض. الميعاد الحر خارج الفترات **مؤجل**. |
| D-07 | وقت فاصل بين الحفلات تحدده القاعة ويدخل في حساب التعارض. |
| D-08 | الحجز المبدئي لا يحتاج عربونًا ولا يقفل الموعد، ويمكن وجود أكثر من حجز مبدئي على نفس الموعد. أول حجز يُؤكد بعربون يأخذ الموعد. للمبدئي مدة صلاحية تحددها القاعة. |
| D-09 | الحجز المبدئي يكفيه: الاسم، الموبايل، المكان، التاريخ، الفترة. |
| D-10 | كل باكيج مرتبط بمكان. سعره يختلف حسب الفترة والموسم. يوم الأسبوع لا يؤثر. |
| D-11 | الباكيج يشمل عددًا أساسيًا من المعازيم، ولكل فرد زيادة سعر محدد. |
| D-12 | الخدمات: سعر ثابت، أو بالعدد، أو بالفرد (تُضرب في عدد المعازيم). |
| D-13 | الفقرات قد تكون من القاعة أو متعهد خارجي، وبعض الأنواع عليها رسوم دخول للمتعهد الخارجي. الفقرات تُسجل كخدمة بسعر وعدد بلا برنامج تفصيلي. |
| D-14 | الباكيج قالب قابل للتخصيص. لكل خدمة مضمنة "مسموح إزالتها؟" و"قيمة خصم عند الإزالة" تحددها القاعة. |
| D-15 | السعر يُثبت (Snapshot) وقت التأكيد ولا يتأثر بتغيير الأسعار لاحقًا، إلا في حالات التعديل والتأجيل الموضحة. |
| D-16 | التعديل بعد التأكيد (إضافة خدمة/زيادة عدد) بالأسعار **الحالية**، ويمكن للموظف تعديل سعر البند يدويًا؛ إن كان أقل من الحالي يُعامل كطلب خصم. |
| D-17 | الخصم يطلبه الموظف ويوافق عليه المدير، ومن يملك صلاحية الموافقة يطبقه مباشرة. |
| D-18 | المدفوعات: عربون ثم أقساط اختيارية، والإجمالي يجب أن يُسدد قبل يوم الفرح. |
| D-19 | الحد الأدنى للعربون إعداد عند القاعة: بدون حد، أو مبلغ ثابت، أو نسبة من الإجمالي. |
| D-20 | سياسة الإلغاء شرائح حسب الأيام المتبقية على الحفلة، والقاعة تختار أساس الحساب: العربون فقط أو كل المدفوع. |
| D-21 | التأجيل بدون رسوم بشرط توفر الموعد. يُعاد حساب **سعر الباكيج فقط** حسب فترة وموسم الموعد الجديد بالأسعار الحالية، والبنود تبقى بأسعارها. |
| D-22 | فرق التأجيل لصالح العميل يصبح رصيدًا يُسوّى باسترداد أو بتحويله لخدمات حسب إعداد القاعة. |
| D-23 | الحفلة التي انتهت وعليها متبقي: تحذير وتمييز فقط، بلا منع. |
| D-24 | الصلاحيات قابلة للتخصيص: المالك (ومن يفوضه) ينشئ الأدوار من قائمة صلاحيات ثابتة في النظام، مع أدوار افتراضية جاهزة. |
| D-25 | سجل عمليات (Audit Log) إلزامي من أول نسخة. |
| D-26 | صورة بطاقة العريس تُرفع مع الحجز. العقد يُطبع (قالب ثابت). إيصال لكل دفعة. |
| D-27 | الطباعة: PDF بمقاس A4 للعقد والتفاصيل والإيصال، وقالب 80 مم للطابعة الحرارية. |
| D-28 | العميل المتكرر: عند كتابة رقم موجود يقترح النظام العميل ويختار الموظف الربط أو الإنشاء، بلا إجبار. |
| D-29 | المصروفات مطلوبة في الـ MVP (لحساب صافي الربح). قائمة التجهيزات مؤجلة. |
| D-30 | أنواع المناسبات قائمة تحددها القاعة؛ اسما العريس والعروسة اختياريان لغير الأفراح. ربط الباكيجات بنوع المناسبة مؤجل. |
| D-31 | طرق الدفع قائمة تحددها القاعة. |
| D-32 | تحصيل الاشتراكات يدوي، ولا يوجد دفع إلكتروني في الـ MVP. |
