# رحلات المستخدم

## UF-01 تجهيز نسخة لمنشأة جديدة (مالك المنتج)
1. إنشاء مشروع قاعدة بيانات جديد ومساحة ملفات.
2. ضبط متغيرات البيئة ونشر نفس الكود.
3. تشغيل الـ Migrations.
4. تشغيل سكريبت الإعداد: اسم المنشأة + حساب المالك (login + كلمة مرور مؤقتة) + الأدوار الافتراضية + القيم الافتراضية للإعدادات.
5. تسليم بيانات الدخول للمالك.

## UF-02 أول دخول للمالك (قائمة الإعداد الموجّهة)
1. تغيير كلمة المرور المؤقتة.
2. قائمة إعداد تعرض المكتمل والناقص بالترتيب:
   بيانات المنشأة ← الأماكن وفتراتها ← الوقت الفاصل ← المواسم (اختياري) ← أنواع المناسبات ← طرق الدفع ← الخدمات ← الباكيجات وأسعارها ← سياسة الإلغاء والعربون والتأجيل ← الموظفون.
   ضبط **شرائح الإلغاء** خطوة إجبارية في هذه القائمة (D-60)؛ المنشأة تُنشأ بلا شرائح، و"مضبوطة" = شريحة واحدة على الأقل ولو 0% (D-67).
   حالة كل خطوة (D-71): بيانات المنشأة مكتملة بالاسم والتليفون والعنوان؛ الأماكن وأنواع المناسبات وطرق الدفع بعنصر نشط واحد على الأقل؛ الوقت الفاصل مكتمل من البداية بقيمته الافتراضية وتُعرض قيمته؛ السياسات بضبط الشرائح؛ المواسم والموظفون اختياريان؛ الخدمات بخدمة نشطة واحدة على الأقل؛ الباكيجات بباكيج نشط على مكان نشط وله سعر عادي (D-77).
3. لا يمكن تأكيد أي حجز قبل وجود مكان نشط واحد على الأقل وباكيج نشط له سعر (على مكان نشط — D-77)، **وضبط شرائح الإلغاء** (D-60).

## UF-03 إنشاء حجز (الرحلة الأساسية)
1. **المكان والموعد:** اختيار المكان، التاريخ، الفترة (نهاري/مسائي/يوم كامل). يعرض النظام المتاح ويقترح المواعيد الافتراضية مع إمكانية تعديلها تعديلًا بسيطًا، ويفحص التعارض فورًا. (يمكن البدء من خانة فارغة في التقويم.)
2. **المناسبة والباكيج والعدد:** نوع المناسبة، الباكيج (من باكيجات المكان)، عدد المعازيم. السعر يُحسب لحظيًا.
3. **التخصيص:** إزالة خدمات مضمنة مسموح إزالتها، إضافة خدمات/فقرات بالكمية، تحديد الخارجي منها.
4. **العميل:** إدخال الموبايل ← اقتراح عميل موجود أو إنشاء جديد؛ اسما العريس والعروسة؛ رفع صورة البطاقة (اختياري في هذه الخطوة).
5. **الملخص:** تفصيل السعر كاملًا، وطلب خصم إن لزم.
6. **الحفظ:**
   - **مبدئي:** يعرض تاريخ انتهاء الصلاحية.
   - **مؤكد:** تسجيل العربون (التحقق من الحد الأدنى) وطريقة الدفع، ثم جدول أقساط اختياري.
7. طباعة/مشاركة الإيصال والعقد.

> الحجز المبدئي يمكن حفظه بعد الخطوة 1 + اسم وموبايل فقط (D-09).

## UF-04 تأكيد حجز مبدئي
فتح الحجز ← استكمال البيانات الناقصة ← تسجيل العربون ← التأكيد. إن ظهر تعارض مع حجز مؤكد يُرفض مع رسالة واضحة.

## UF-05 تحصيل قسط
من شاشة التحصيلات أو صفحة الحجز ← تسجيل المبلغ وطريقة الدفع ← حفظ ← طباعة الإيصال (A4 أو 80 مم أو PDF للمشاركة).

## UF-06 طلب خصم والموافقة
الموظف يطلب خصمًا بمبلغ وسبب ← يظهر في "الموافقات" وفي الرئيسية للمدير ← موافقة أو رفض ← يُعاد حساب الإجمالي عند الموافقة.

## UF-07 تعديل حجز مؤكد
إضافة/إزالة بنود أو تغيير العدد ← عرض الإجمالي قبل/بعد ← تعديل سعر بند يدويًا (إن كان أقل يتحول لطلب خصم) ← حفظ ← يُسجل التعديل.

## UF-08 التأجيل
اختيار تاريخ وفترة جديدة ← فحص التوفر ← عرض سعر الباكيج الجديد والفرق ← (فرق على العميل: يضاف للمتبقي | فرق لصالحه: اختيار استرداد أو خدمات حسب السياسة) ← تعديل الأقساط المتجاوزة ← تأكيد.

## UF-09 الإلغاء
اختيار إلغاء ← يعرض النظام الأيام المتبقية والشريحة والأساس والمبلغ المقترح ← إمكانية تعديل المبلغ بسبب ← تأكيد ← حركة استرداد + إيصال ← تحرير الموعد.

## UF-10 تسجيل مصروف
المصروفات ← إضافة: التصنيف، المبلغ، التاريخ، الوصف، ربط بحجز (اختياري).

## UF-11 إدارة الموظفين
الموظفون ← إضافة موظف (الاسم، login، كلمة مرور مؤقتة، الأدوار) ← تعطيل/تفعيل ← إعادة تعيين كلمة المرور. الأدوار ← إنشاء/تعديل دور باختيار الصلاحيات.

## UF-12 المتابعة اليومية
الرئيسية: حفلات اليوم والأسبوع، المبدئي القريب من الانتهاء، المتأخرات، الحفلات القريبة وعليها متبقي، الخصومات المعلقة.
