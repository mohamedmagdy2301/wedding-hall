# الخطوة 9.0 — الوصول لـ R2 بواجهة S3 (P9-01)

> الحالة: **محليًا مكتمل (2026-10-25).** الجزء على R2 الحقيقي مستني تفعيل R2 على حساب Cloudflare (`wrangler r2 bucket list` ← "Please enable R2 through the Cloudflare Dashboard" [10042]).

## المكتبة

`aws4fetch` 1.0.20 (2024-08، بلا اعتماديات، مبنية على `fetch` و WebCrypto، ومعمولة لـ Workers). بتوقّع طلبات S3 (SigV4) وبتطلع روابط موقّعة (`signQuery`).

## البديل المحلي لـ R2

MinIO بطّل ينشر صور Docker (`minio/minio` و `quay.io/minio/minio` مرفوضين وقت التجربة)، فاتستخدم **versitygw** v1.9.0 (Apache-2.0) بواجهة S3 فوق مجلد. ملاحظة: versitygw بيطلب `region` = `us-east-1`، و R2 بيقبل `auto`؛ فالمنطقة متغير بيئة (`R2_REGION`).

## التجربة

نفس الكود (`put` 1 ميجا، رابط موقّع 3 ثواني، فتح بلا توقيع، رابط متلاعب فيه، فتح بعد 5 ثواني، مسح، فتح بعد المسح):

| الخطوة | Node 22 | workerd (`wrangler dev`) |
|---|---|---|
| رفع | 200 | 200 |
| الرابط الموقّع | 200، 1,048,576 بايت، `image/jpeg` | 200، نفس البايتات والنوع |
| فتح من غير توقيع | 403 | 403 |
| رابط متلاعب فيه | 403 | 403 |
| الرابط بعد ما خلص | **403** | **403** |
| مسح | 204 | 204 |
| فتح بعد المسح | 404 | 404 |

## على R2 الحقيقي (بعد التفعيل)

نفس التجربة من Worker التطوير بـ `global_fetch_strictly_public` (endpoint الـ R2 عام فمش هيتمنع)، وتتسجل النتيجة هنا.
